# Milestone Requirements: v2.0 - Desktop UI Refactor

## 1. Overview
This milestone focuses on a comprehensive visual and layout refactor of the existing web-based family meal planner to align perfectly with the high-fidelity Desktop version of the screens designed in the Stitch Project `WFM-AI-MEALPLANNER`.

## 2. In-Scope Components & Screens
The following screens and components must be refactored to match their corresponding Desktop v2 designs in Stitch:

- **Landing & Login (Desktop) [v2]**:
  - Screen ID: `c9f136a1fa5e460aa641c79e890535d7`
  - Focus: Minimalist layout, large serif typography, "warm paper" feel.

- **Your Household (Desktop) [v2]**:
  - Screen ID: `f8c7fa3d84eb42ceb093815610869ac0`
  - Components: `MemberCard` and `ProfileForm` must be updated according to the `.stitch/designs/` HTML files.
  - Focus: High-end editorial multi-column arrangements.

- **Weekly Meal Planner (Desktop) [v2]**:
  - Screen ID: `65a5820a1d224c7dadb1c23f54008c85`
  - Focus: 1200px container width, daily column distribution, interactive slot designs.

- **Recipe Details (Desktop) [v2]**:
  - Screen ID: `3d97ec4cf8e34bf5b32bee839b69b856`
  - Focus: "Cookbook side-drawer" aesthetic with 65ch max-width for instructions.

- **The Market Ledger (Desktop)** (Shopping List):
  - Screen ID: N/A (Based on `ShoppingList.html` in `.stitch/designs/`).
  - Focus: Category-based grouping with a print-ready cookbook feel.

## 3. Out-of-Scope
- **Settings Screen**: No UI changes required at this time.
- **Backend/Logic**: No changes to existing AI logic, Supabase schema, or authentication flows unless strictly necessitated by the new UI layout.

## 4. Technical Constraints
- **Styling**: All CSS must remain Vanilla CSS. No Tailwind or other utility-first frameworks.
- **Google Stitch**: All UI components and designs must be sourced from the Stitch project via the `stitch-design` skill.
- **Aesthetic**: Maintain the "minimalist earthy aesthetic," "cookbook layout," and "tactile UI elements" defined in `GEMINI.md`.

## 5. Success Criteria
- [ ] Each screen precisely matches the Desktop v2 design from Stitch.
- [ ] Responsive behavior for non-desktop devices is maintained (fallback to single-column stack).
- [ ] Components (MemberCard, ProfileForm) utilize the new Stitch-generated HTML/CSS structure.
- [ ] The "Cookbook" atmosphere is consistently applied across all refactored pages.
