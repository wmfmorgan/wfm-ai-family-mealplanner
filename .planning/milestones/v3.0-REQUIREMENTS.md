# Milestone v3.0 - Meal Generation Refinement

## Context
Following the successful completion of the Core Engine (v1.0) and Desktop UI Refactor (v2.0), the system now has a solid visual foundation. However, the meal generation process remains a "all-or-nothing" experience. This milestone focuses on giving users surgical control over their weekly plan and improving the quality/diversity of AI-generated content.

## User Requirements

### 1. Granular Slot Control
- [MGR-01] **Delete/Clear Slot**: Users can remove a meal from any slot (manual entry or AI-generated) without affecting other slots.
- [MGR-02] **Refresh Single Slot**: Users can request a new AI suggestion for a specific slot, considering the existing context of the week (to avoid duplicates).

### 2. Plan Quality & Diversity
- [MGR-03] **Duplicate Prevention**: Implement system-level checks to ensure the same recipe (or highly similar meals) aren't suggested twice in the same week.
- [MGR-04] **Ingredient Specificity**: Enhance prompts to provide more detailed ingredient lists (quantities, prep notes) based on household "Chef's Notes".
- [MGR-05] **Sanitization Agent**: A post-generation AI pass to review the whole plan for balance, diversity, and strict adherence to household dietary profiles.

### 3. UI/UX Feedback
- [MGR-06] **Generation Progress**: Visual indicators for multi-step generation (e.g., "Drafting Recipes", "Verifying Sensitivities", "Consolidating List").
- [MGR-07] **Tactile Controls**: Integrated slot actions (Refresh/Delete) that match the minimalist earthy aesthetic.

## Technical Requirements

### 1. State Management
- Update `plannerService` and `MealPlanner` state to handle single-slot updates and deletions.
- Ensure Supabase schema supports "clearing" slots without deleting the underlying weekly plan record.

### 2. AI Layer
- Update `ai-proxy` to support single-slot generation prompts.
- Implement a post-processing "Sanitize" function in Supabase Edge Functions.

### 3. Verification Criteria
- [ ] Individual slot clear/refresh verified in UI and DB.
- [ ] No duplicate recipes generated in a 10-week test run.
- [ ] Visual feedback displays during each phase of generation.
