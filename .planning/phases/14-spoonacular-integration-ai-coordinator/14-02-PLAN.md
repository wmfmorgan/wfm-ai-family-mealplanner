Create `supabase/functions/select-meals/index.ts` as a Deno Edge Function using the shared auth and AI modules.

Implement this exact request contract:
```json
{
  "household_id": "uuid",
  "members": [{ "name": "Alice", "nutrition_profile": { "...": "..." } }],
  "week_start_date": "YYYY-MM-DD",
  "matrix": {
    "0": ["breakfast", "dinner"],
    "1": ["dinner"],
    "2": ["breakfast", "lunch"],
    "3": []
  }
}
```

Behavior:
1. `verifyAuth(req)` first
2. Load the caller's `generation_preferences` from `public.households`
3. Resolve final scope:
   - use request `matrix` when provided
   - otherwise use `generation_preferences.matrix` from Task 1 of Plan 14-01
4. Build directive targets directly from matrix cells, limited to `breakfast | lunch | dinner`, preserving sparse selections exactly as stored
5. Call `callAI` once with `role: 'coordinator'`, `responseFormat: { type: 'json_object' }`, `edgeFunction: 'select-meals'`, and `householdId`
6. Validate the parsed coordinator JSON and return:
```json
{
  "week_start_date": "2026-04-19",
  "matrix": {
    "0": ["breakfast", "dinner"],
    "1": ["dinner"],
    "2": ["breakfast", "lunch"]
  },
  "directives": [
    {
      "day": 0,
      "meal_type": "breakfast",
      "query": "high protein greek yogurt bowl",
      "cuisine": null,
      "diet": "vegetarian",
      "min_calories": 400,
      "max_calories": 550,
      "intolerances": ["dairy"],
      "exclude_ingredients": ["almond", "walnut"],
      "fallback_reason": null
    }
  ]
}
```

Prompt requirement: the system prompt must explicitly instruct the coordinator to output directives only and forbid recipe instructions, shopping lists, or recipe prose. It must require a calorie range for every directive by emitting both `min_calories` and `max_calories`. Treat the incoming matrix as the source of truth for which day/meal cells are enabled; do not regenerate the cartesian product of flat day and meal arrays.

Create `supabase/functions/select-meals/index.test.ts` with Deno tests covering:

- explicit request matrix overrides persisted preferences
- a sparse matrix such as `{ "1": ["dinner"], "3": ["breakfast"] }` produces directives only for those exact cells
- response contains `directives` and omits `recipes`
