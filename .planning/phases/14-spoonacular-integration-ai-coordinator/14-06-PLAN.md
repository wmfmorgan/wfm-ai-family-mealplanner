<objective>
Fix the select-meals HTTP 500 that surfaces when the coordinator AI is asked to generate a full 21-cell weekly meal matrix.

Root cause: ROLE_CONFIG sets coordinator max_tokens to 1024. A full 7-day × 3-meal-type directive set requires ~2200–2400 tokens. The model truncates its output, JSON.parse throws a SyntaxError, and the catch block swallows all detail and re-throws as a generic 500.

Purpose: Restore end-to-end meal generation so the MealPlanner can greet the user with grounded Spoonacular slots.
Output: Two modified files — ai-client.ts with a higher token budget, index.ts with a diagnostic pre-parse guard.
</objective>
