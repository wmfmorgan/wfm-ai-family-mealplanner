## Objective
Adopt a new top-level navigation structure (Header/Footer/Navbar) from the Stitch project (screen ID `f8c7fa3d84eb42ceb093815610869ac0`) for desktop viewports, while preserving the mobile `BottomTabBar`. Switch to Material Icons.

## Implementation Steps
1. **Create Header & Footer Components**:
   - Implement `Header.tsx` with top-level navigation (Planner, Household, Recipes, Settings). Use "Newsreader" for the logo and "Manrope" for navigation links. Add Material Icons for utility icons (notifications, user profile).
   - Implement `Footer.tsx` with standard site links and aesthetic styling matching the "warm paper" background.
2. **Update App Layout Shell**:
   - Update `Shell.tsx` to include `Header` and `Footer`.
   - Remove or deprecate `Sidebar.tsx` usage if it was only for desktop navigation.
3. **Responsive CSS Media Queries**:
   - In `Layout.css`, use CSS media queries to conditionally display the `Header` and `Footer` on desktop (e.g., `>= 768px`) and hide the `BottomTabBar`. Conversely, hide the `Header` and `Footer` on mobile (`< 768px`) and show the `BottomTabBar`.
4. **Icons Refactor**:
   - Ensure the `index.html` or global CSS includes the Material Icons font if not already present. Convert any Lucide/Emoji icons in the shell components to Material Icons.

## Verification & Testing
- Verify that resizing the browser to desktop width shows the new Header/Footer and hides the BottomTabBar.
- Verify that shrinking the browser to mobile width hides the Header/Footer and shows the BottomTabBar.
- Ensure no layout regressions occur in the main content area.
