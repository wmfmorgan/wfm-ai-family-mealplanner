# Phase 07: Your Household (Desktop) [v2] - Plan Part 2: Household Components Refactor

## Objective
Refine the Household screen aesthetics (MemberCard, ProfileForm, MemberGrid) to align with the Milestone v2.0 Desktop UI specifications without changing component logic. Optimize the grid container for a 1200px desktop width.

## Key Files & Context
- `src/pages/Household/Household.tsx` (Modified)
- `src/pages/Household/Household.css` (Modified)
- `src/components/Household/MemberGrid.css` (Modified)
- `src/components/Household/MemberCard.tsx` (Modified)
- `src/components/Household/MemberCard.css` (Modified)
- `src/components/Household/ProfileForm.tsx` (Modified)
- `src/components/Household/ProfileForm.css` (Modified)

## Implementation Steps
1. **Refined Grid Container**:
   - Update `Household.tsx` and `Household.css` to wrap content in a `max-width-planner` (1200px) container.
   - Adjust `MemberGrid.css` to optimize spacing for the desktop "editorial" feel.
2. **Typography Updates**:
   - In `MemberCard.tsx` and `ProfileForm.tsx`, ensure headings use `Newsreader` (Serif) and body/forms use `Manrope` (Sans-Serif).
3. **Visual Aesthetics**:
   - Apply the "Verdant Table" palette (e.g., Sage Green accents, warm paper backgrounds) as established in Phase 06 to the cards and forms. Minor CSS tweaks to padding, borders, and shadows to match the Stitch design.
4. **Icons Refactor**:
   - Update any icons within `MemberCard` (e.g., edit, delete) and `ProfileForm` to use Material Icons.

## Verification & Testing
- Verify that multi-member management (Add, Edit, Delete) works correctly.
- Verify that the layout spans up to 1200px gracefully on large monitors.
- Ensure the typography and colors correctly match the v2 design system rules.
